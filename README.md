### What is void?

UI framework with reactivity, focused on simplicity, code unambiguity and performance.

- Own syntax (`.void` files) with JSX markup.
- Minimal runtime.
- Fine grained DOM updates.
- Simple reactive primitives - `signal` and `effect`.
- 100% TypeScript.
